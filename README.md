# 投放观测站

![投放观测站企鹅图标](penguin.png)

腾讯广告（广点通）近 7 天分日报表助手，适用于 Chrome 和 Microsoft Edge。

[下载安装包](https://github.com/toufang-lab/ad-observation-station/releases/latest) · [安装说明](安装说明.md) · [使用说明](使用说明.md)

## 能看什么

- 在账户、项目、营销单元和创意行内展开近 7 天，支持逐个查看和当前页全开。
- 对比每日消耗、注册成本、ECPM、有效IPU、首日 ROI、3 日和 7 日倍率。
- 可独立开关列表标签和明细列，保留常用指标。

## 安装

打开 [Releases](https://github.com/toufang-lab/ad-observation-station/releases/latest)，下载 Assets 下名称以 `ad-observation-station-v` 开头的 ZIP，并解压。打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`，开启开发者模式，点击「加载已解压的扩展程序」，选择带 `manifest.json` 的文件夹。回腾讯广告后台刷新报表页。

插件沿用浏览器中已有的腾讯广告登录状态，在已授权的报表页展示数据。查看广告报表需要相应的腾讯广告账号权限。
